# cmdAbl

A command palette for Ableton Live. Press `:` while Live is focused to open a keyboard-driven
command input with fuzzy filtering, tab completion and POSIX-style flag arguments.

- **Install and use cmdAbl:** see the [README on GitHub](https://github.com/MarvinHauke/cmdAbl#readme).
- **Latest release:** [GitHub Releases](https://github.com/MarvinHauke/cmdAbl/releases/latest).
- **Guides:** how releases, the `pakabl` extension list and CI work — start with the
  [guides overview](guides/README.md).
